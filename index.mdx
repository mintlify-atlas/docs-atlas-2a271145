The Microsoft Graph SDK for Python gives you a fluent, async-first interface to the [Microsoft Graph API](https://docs.microsoft.com/graph/overview). With strongly-typed model classes, built-in authentication, and automatic pagination, you can access users, groups, mail, files, and hundreds of other Microsoft 365 resources from your Python applications.

## Why use this SDK?

<CardGroup cols={2}>
  <Card title="Async-first" icon="bolt">
    Every request returns a coroutine. Use `asyncio`, `anyio`, or `trio` to run concurrent Graph API calls efficiently.
  </Card>
  <Card title="Strongly typed" icon="shield-check">
    Auto-generated model classes with fully typed properties match the Graph API v1.0 metadata exactly.
  </Card>
  <Card title="Fluent request builders" icon="wand-magic-sparkles">
    Chain methods like `client.users.by_user_id(id).messages.get()` with IDE autocomplete at every step.
  </Card>
  <Card title="Azure Identity integration" icon="key">
    Drop in any Azure Identity credential — `ClientSecretCredential`, `DeviceCodeCredential`, and more.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Install the SDK">
    ```bash
    pip install msgraph-sdk
    ```
  </Step>
  <Step title="Create a GraphServiceClient">
    ```python
    from azure.identity import ClientSecretCredential
    from msgraph import GraphServiceClient

    credential = ClientSecretCredential(
        tenant_id="TENANT_ID",
        client_id="CLIENT_ID",
        client_secret="CLIENT_SECRET",
    )
    client = GraphServiceClient(credentials=credential, scopes=["https://graph.microsoft.com/.default"])
    ```
  </Step>
  <Step title="Make your first API call">
    ```python
    import asyncio

    async def get_users():
        users = await client.users.get()
        for user in users.value:
            print(user.display_name, user.mail)

    asyncio.run(get_users())
    ```
  </Step>
</Steps>
