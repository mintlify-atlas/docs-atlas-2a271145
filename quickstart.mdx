This guide walks through installing the SDK, configuring credentials, and retrieving a user from Microsoft Graph using application permissions.

## Prerequisites

- Python 3.9 or later
- An Azure AD app registration with a client secret and the `User.Read.All` (or similar) application permission granted and admin-consented. See [Register your app with the Microsoft Identity Platform](https://docs.microsoft.com/graph/auth-register-app-v2) for setup steps.
- Your **tenant ID**, **client ID**, and **client secret** from the app registration.

<Note>
  All requests to Microsoft Graph through this SDK are **asynchronous**. Every API method returns a coroutine that must be awaited inside an `async` function and run with `asyncio.run()` (or an equivalent async runner). The SDK does not provide synchronous wrappers.
</Note>

## Steps

<Steps>
  <Step title="Install the SDK">
    Install `msgraph-sdk` from PyPI:

    ```bash
    pip install msgraph-sdk
    ```

    The package is large; the first install may take a few minutes.
  </Step>

  <Step title="Set up credentials">
    Use `ClientSecretCredential` from `azure.identity.aio` to authenticate with application permissions. This credential is suitable for daemon apps and background services that run without a signed-in user.

    ```python
    from azure.identity.aio import ClientSecretCredential

    credential = ClientSecretCredential(
        'tenant_id',
        'client_id',
        'client_secret'
    )
    scopes = ['https://graph.microsoft.com/.default']
    ```

    Replace `tenant_id`, `client_id`, and `client_secret` with the values from your Azure AD app registration. The scope `https://graph.microsoft.com/.default` requests all application permissions that have been granted to the app.
  </Step>

  <Step title="Initialize GraphServiceClient">
    Create a `GraphServiceClient` by passing the credential and scopes. This object is the entry point for all API calls.

    ```python
    from msgraph import GraphServiceClient

    client = GraphServiceClient(credentials=credential, scopes=scopes)
    ```

    The client uses the default `https://graph.microsoft.com` base URL and a pre-configured `httpx.AsyncClient` with retry and redirect middleware.
  </Step>

  <Step title="Make a request">
    Call `client.users.by_user_id()` to fetch a specific user by their user principal name or object ID. All request methods are async and must be awaited.

    ```python
    import asyncio

    async def get_user():
        user = await client.users.by_user_id('userPrincipalName').get()
        if user:
            print(user.display_name)

    asyncio.run(get_user())
    ```
  </Step>

  <Step title="Handle the response">
    The response is deserialized into a strongly-typed `User` model. Access any property directly as an attribute. If the request fails, `get()` raises an `APIError` with a structured error message.

    ```python
    from kiota_abstractions.api_error import APIError

    async def get_user():
        try:
            user = await client.users.by_user_id('userPrincipalName').get()
            if user:
                print(user.display_name)
        except APIError as e:
            print(f'Error: {e.error.message}')

    asyncio.run(get_user())
    ```
  </Step>
</Steps>

## Complete example

The following is a complete, self-contained script from the SDK README:

```python
import asyncio
from azure.identity.aio import ClientSecretCredential
from msgraph import GraphServiceClient

credential = ClientSecretCredential(
    'tenant_id',
    'client_id',
    'client_secret'
)
scopes = ['https://graph.microsoft.com/.default']
client = GraphServiceClient(credentials=credential, scopes=scopes)

async def get_user():
    user = await client.users.by_user_id('userPrincipalName').get()
    if user:
        print(user.display_name)
asyncio.run(get_user())
```
